# 素材接收流程（聊天窗口直传）

目标：你只需要在聊天里发图片/链接/文字，不用自己命名、不用自己放目录；其余（裁剪压缩、落盘、改代码、commit+push、部署验证）我来做。

## 你需要发什么

### 1) 图片（推荐）
- 直接把图片/截图拖进聊天发送（原图更好）
- 同一组素材可一次发多张

### 2) 链接
- 新闻链接、社媒链接、Google Maps 链接等直接粘贴

### 3) 一句话说明用途（必填）
只要回答“用在什么地方 + 替换/新增哪个位置”即可。

## 我会做什么
- 识别用途 → 生成稳定的文件命名 → 放入正确目录（例如 `public/images/...`）
- 必要时：裁剪/压缩/转格式，保证网页加载速度与清晰度平衡
- 更新代码引用（例如 `siteData.ts` / `page.tsx` 等）
- 本地构建通过后 commit+push，触发 Vercel 自动部署

## 例外情况（仅当你无法在聊天里发文件）
我会给你一份“文件名清单 + 放置目录”，你只要按文件名保存到对应目录即可。
